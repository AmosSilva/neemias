Política de privacidade do Neemias

  • Quem usa: só o criador do Neemias, com as próprias contas Google. Ninguém mais pode usá-lo.
  • O que o Neemias acessa no Google: a lista das agendas do usuário; os eventos das agendas que são dele, só para leitura; e as agendas que o próprio Neemias cria, nas quais pode criar e mudar eventos.
  • Para quê: mostrar a agenda, lembrar compromissos e registrar o tempo das atividades do próprio usuário.
  • Onde ficam os dados: num servidor privado do usuário, em disco cifrado. Os dados não são vendidos, não são compartilhados e não são usados para publicidade.
  • Uso Limitado: o uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
  • Como revogar o acesso: a qualquer momento, em myaccount.google.com/permissions.
